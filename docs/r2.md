# 配置 R2 静态前端

浏览器在实例子域名登录。网关返回启动页，浏览器再从 `https://mower.231240092.xyz` 读取实例指定的构建。状态请求和 WebSocket 使用原有中转域名和端口。

1. 在管理 `231240092.xyz` 的 Cloudflare 账号打开 **R2 Object Storage**，创建 Standard 存储桶 `mower-ui`。桶只存公开前端资源。
2. 进入该桶的 **Settings → Custom Domains → Add**，输入 `mower.231240092.xyz`，确认 Cloudflare 建议的 DNS 记录，等待状态变为 Active。中转机继续沿用 `free.mower.work:58000`。详见 [R2 自定义域名](https://developers.cloudflare.com/r2/buckets/public-buckets/)。
3. 在桶的 **Settings → CORS Policy** 保存下面的策略。每个实例使用不同的浏览器 Origin，公开静态文件允许跨域 GET 和 HEAD。浏览器访问 R2 时无需登录 Cookie 或实例 Token。[R2 CORS](https://developers.cloudflare.com/r2/buckets/cors/)

```json
[{"AllowedOrigins":["*"],"AllowedMethods":["GET","HEAD"]}]
```

4. 在 R2 的 **Manage API Tokens** 创建 **Object Read & Write** 凭据，作用范围选择这一个桶。记录 Account ID、Access Key ID 和 Secret Access Key。[R2 API 凭据](https://developers.cloudflare.com/r2/api/tokens/)
5. 在 **ArkMowers/arknights-mower → Settings → Secrets and variables → Actions** 配置下表。Windows 网关只需知道公开域名。

| 类型 | 名称 | 值 |
| --- | --- | --- |
| Variable | `R2_ACCOUNT_ID` | Cloudflare Account ID |
| Variable | `R2_BUCKET` | `mower-ui` |
| Secret | `R2_ACCESS_KEY_ID` | R2 Access Key ID |
| Secret | `R2_SECRET_ACCESS_KEY` | R2 Secret Access Key |

6. 使用包含 R2 发布流程的分支运行 GitHub Actions「发布中转前端」。发布器先上传共享文件，最后创建 `builds/<构建标识>/manifest.json`。用实例随包的 `ui/dist/relay-ui.json` 中的 `build` 替换占位符，在浏览器打开 `https://mower.231240092.xyz/builds/<构建标识>/manifest.json` 可验证发布。已发布的构建目录和它引用的共享文件供旧实例继续使用。

网关默认静态域名已设为 `https://mower.231240092.xyz`。临时测试也可以将其他可信 HTTPS 静态站点的地址写入网关工作目录的 `ui-origin.txt`，再重启网关。R2 分配的开发地址只用于测试。
