# 服务端行为说明

本项目负责 Mower 中转服务，独立安装及发布，不导入 `arknights_mower`。Mower 主仓负责内置客户端、本地用户名和密码验证、实例 token 及设备操作；服务通过[协议 v1](../mower_relay_server/protocol.py)连接。网关使用客户端随包的构建标识选择静态站点已发布的界面。

## HTTPS 与准入

服务直接加载 PEM 证书完整链及匹配私钥，最低使用 TLS 1.2，唯一监听端口为 58000。证书格式错误、缺失或私钥不匹配时启动失败，不回退到 HTTP。自动续签只改变磁盘文件，完成后需重启服务加载；客户端自动重连，浏览器重新登录。

用户连接地址为 `wss://free.mower.work:58000/__mower/connect`，提交独立随机凭据，网关按凭据摘要查找启用记录，并在握手响应中返回分配的子域名。凭据须唯一对应一条启用记录，每个子域名同时只接受一个实例。SQLite 凭据数据库保存凭据 SHA-256 摘要、子域名、外部用户标识及启用状态；源码不含通用服务密钥。数据库不可读时拒绝准入和已有用户访问。

管理 API 与管理网页共享可配置入口，默认路径为 `/admin/`，以[独立管理密钥](admin-api.md)授权。会话签名密钥和管理密钥分别生成，重启不覆盖已有文件。生产密钥、证书、注册数据和前端文件不纳入 Git。

## 浏览器认证及操作范围

用户打开 `https://<名称>.free.mower.work:58000` 后，登录信息经 TLS 交给本地 Mower 验证。服务端不持久化用户名、密码校验值、密码或实例 token；这些数据仍会在网关内存中经过，TLS 终止方具有读取传输内容的能力。

认证成功签发八小时 Cookie，带 Secure、HttpOnly、SameSite=Strict，并绑定子域名与当前连接。断开、重连和吊销使原会话失效。浏览器通过 HTTP Basic 认证提示输入非空密码，本地客户端验证用户名和密码。实例操作继续校验 token。每个名称每分钟最多五次登录尝试。

网关将业务请求转给当前连接的实例，由 Flask 匹配路由、方法并检查实例 token 和操作权限。两端都执行[本机管理限制](../mower_relay_server/protocol.py)，拦截原生文件选择、中转与多开管理、软件维护、备份导入和进程控制等操作。读取进程状态、导出备份等请求仍按实例权限处理。WebSocket 支持日志和聊天订阅。

网关只向实例转发 GET、POST、PUT、PATCH 和 DELETE。部分历史 GET 接口会操作任务，Flask 自动注册的 HEAD 会执行同一处理函数，因此网关在转发前拒绝业务 HEAD。

新增普通 HTTP 接口只需更新实例。改变本机管理限制或传输协议时，两端需同步发布。更新期间，旧版本仍执行自身的限制。网关继续校验请求目标、请求头、响应格式和大小，静态页面与脚本由官方前端分发。

开源协议不能证明用户运行未经修改的 Mower；合法凭据持有人仍可能伪装协议数据。服务以审核、能力范围、限额、查询及吊销控制滥用，不承诺阻止一切伪装。

## 资源及生命周期

同一来源 IP 每秒补充 20 次入口请求额度，最多累计 40 次。最多保留 4096 个来源记录，达到上限时淘汰最久未访问的来源。每个客户端连接最多八个待响应操作和四个浏览器 WebSocket，每分钟最多 600 个 HTTP 或登录操作、64 MiB 动态中转数据。

用户请求体及响应最多 6 MiB，管理请求体最多 4 KiB，浏览器 WebSocket 消息最多 64 KiB。业务响应预算为 30 秒，登录验证为 15 秒，握手及发送操作使用有限预算。超时操作不自动重放，不能把超时视为本地动作已回滚。关闭服务会关闭客户端及浏览器订阅。

### 凭据日流量配额

网关按北京时间自然日为每份启用的接入凭据累计双向流量，默认每天 1 GiB。计量点是网关与实例之间的 WSS 文本消息，每条按实际 UTF-8 字节数计一次。HTTP 请求和响应包含 JSON 封装及 Base64，日志、聊天、登录和实例握手消息也计入。已接入实例发送的无效二进制消息按接收字节数计入后断开。网关发出的订阅关闭通知用于释放资源，免计。浏览器直接下载的 R2 资源、网关网页、TLS 及 WebSocket 协议开销不在这项配额内。

每条消息转发前，网关在 SQLite 写事务中核对当前凭据，预扣整条消息的字节数。并发请求共用同一余额。发送失败时已扣用量保留。凭据记录只保存最近使用日期、当天已扣字节数和告警状态。改名、重新连接和重启均保留用量。管理员吊销并重新签发会产生独立凭据。

当天首次达到 80% 时写入预警日志。恰好用完额度时允许最后一条消息通过；下一条消息放不下时整条拒绝并保留已扣用量。两种情况都会记录限额告警，当天暂停该凭据。管理员可查询预警和限额状态。日志仅含子域名、日期、已用字节和额度。北京时间次日零点恢复，无需管理员重启或重新签发。管理员在当天调高全局额度时，已暂停的凭据仍按原定时间恢复。新请求和重连收到 HTTP 429；已开始的 HTTP 操作可能已经在实例执行，网关不会自动重试。

访问日志关闭，避免记录 URL 中的实例 token；服务不记录请求体或用户凭据。独立测试覆盖 TLS 启动、管理鉴权前无副作用、准入、会话隔离、用途限制和限额。Mower 主仓另维护可选联调测试，验证实际客户端、协议一致性和日志订阅。


## 多版本前端

网关在实例子域名完成认证，返回带构建标识的启动页。浏览器从 [R2 静态域名](r2.md) 读取对应清单、脚本、样式和图片，HTTP 操作与日志订阅继续发往同源网关。静态域名由管理员设置，客户端仅能指定 64 位十六进制构建标识。清单暂不可用时网页提供重试。网关在握手时拒绝缺少构建标识的实例。
