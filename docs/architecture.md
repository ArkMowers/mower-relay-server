# 服务端行为说明

本项目负责 Mower 中转服务，独立安装及发布，不导入 `arknights_mower`。Mower 主仓负责内置客户端、本地用户名和密码验证、实例 token 及设备操作；服务通过[协议 v1](../mower_relay_server/protocol.py)连接。前端由管理员准备的可信目录提供，不接受客户端发布网页。

## HTTPS 与准入

服务直接加载 PEM 证书完整链及匹配私钥，最低使用 TLS 1.2，唯一监听端口为 58000。证书格式错误、缺失或私钥不匹配时启动失败，不回退到 HTTP。自动续签只改变磁盘文件，完成后需重启服务加载；客户端自动重连，浏览器重新登录。

用户连接地址为 `wss://free.mower.work:58000/__mower/connect`，提交管理员批准的名称及独立随机凭据，完成版本握手。未知凭据、其他名称及重复连接均被拒绝。注册文件仅保存凭据 SHA-256 摘要、子域名、外部用户标识及启用状态；源码不含通用服务密钥。注册文件不可读时拒绝准入和已有用户访问。

管理 API 位于同一服务的 `/admin/`，以[独立管理密钥](admin-api.md)授权。会话签名密钥和管理密钥分别生成，重启不覆盖已有文件。生产密钥、证书、注册数据和前端文件不纳入 Git。

## 浏览器认证及操作范围

用户打开 `https://<名称>.free.mower.work:58000` 后，登录信息经 TLS 交给本地 Mower 验证。服务端不持久化用户名、密码校验值、密码或实例 token；这些数据仍会在网关内存中经过，TLS 终止方具有读取传输内容的能力。

认证成功签发八小时 Cookie，带 Secure、HttpOnly、SameSite=Strict，并绑定子域名与当前连接。断开、重连和吊销使原会话失效。本地密码至少八字符，由客户端执行验证；密码登录不替代实例 token。每个名称每分钟最多五次登录尝试。

只有[明确列出的 HTTP 操作](../mower_relay_server/protocol.py)及 `/log`、`/ws/chat` WebSocket 可以分派。协议不提供目标地址、目标端口、任意 URL 或通用 TCP 流；远程操作交给 Mower 当前进程的 Flask 应用，沿用其 token 校验。软件安装、本地文件选择、通用导入、进程管理及中转设置不在允许范围内。

JSON、有限的纯文本、截图和强制下载的导出文件按对应响应类型校验。客户端响应不能发布 HTML、脚本、Cookie 或重定向。可信静态目录只包含匹配客户端版本的前端资源，不包含工作目录中的证书或数据。新增 API 必须显式检查两端允许范围，不自动放行未来路由。

开源协议不能证明用户运行未经修改的 Mower；合法凭据持有人仍可能伪装协议数据。服务以审核、能力范围、限额、查询及吊销控制滥用，不承诺阻止一切伪装。

## 资源及生命周期

同一来源 IP 每秒补充 20 次入口请求额度，最多累计 40 次。最多保留 4096 个来源记录，达到上限时淘汰最久未访问的来源。每个客户端连接最多八个待响应操作和四个浏览器 WebSocket，每分钟最多 600 个 HTTP 或登录操作、64 MiB 动态中转数据。

用户请求体及响应最多 6 MiB，管理请求体最多 4 KiB，浏览器 WebSocket 消息最多 64 KiB。业务响应预算为 30 秒，登录验证为 15 秒，握手及发送操作使用有限预算。超时操作不自动重放，不能把超时视为本地动作已回滚。关闭服务会关闭客户端及浏览器订阅。

访问日志关闭，避免记录 URL 中的实例 token；服务不记录请求体或用户凭据。独立测试覆盖 TLS 启动、管理鉴权前无副作用、准入、会话隔离、用途限制和限额。Mower 主仓另维护可选联调测试，验证实际客户端、协议一致性和日志订阅。
